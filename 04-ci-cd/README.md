# Módulo 04 - CI/CD

Este módulo se centra en la integración y el despliegue continuo, automatizando la compilación, los tests y la publicación de imágenes con Jenkins y GitHub Actions.

## 🧠 Objetivos

- Crear pipelines declarativas en Jenkins con un `Jenkinsfile`.
- Ejecutar Jenkins en local con Docker y usar Docker in Docker para los builds.
- Usar una imagen Docker como build runner en Jenkins.
- Crear workflows de CI y CD en GitHub Actions.
- Publicar imágenes en el container registry de GitHub.
- Ejecutar tests e2e o crear una custom JavaScript Action.

## 🛠️ Tecnologías utilizadas

- **Jenkins**: Servidor de automatización para pipelines CI/CD.
- **Gradle**: Compilación y tests del proyecto Java.
- **Docker**: Ejecución de Jenkins y de los build runners.
- **GitHub Actions**: Workflows de CI/CD sobre GitHub.
- **GitHub Container Registry**: Registro de imágenes Docker.

## ✅ Pre-requisitos

- Docker
- Cuenta de GitHub
