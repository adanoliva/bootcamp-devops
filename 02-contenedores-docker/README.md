Módulo 02 - Contenedores Docker

Este módulo se centra en el uso de contenedores mediante Docker, abordando tanto el consumo como la creación de contenedores, así como su integración en entornos de desarrollo y DevOps.

🧠 Objetivos

Comprender el concepto de contenedores y su diferencia frente a máquinas virtuales.

Aprender a trabajar con imágenes Docker y contenedores.

Crear y ejecutar contenedores propios.

Gestionar el ciclo de vida de los contenedores.

Configurar la comunicación entre contenedores.

Proporcionar persistencia de datos mediante volúmenes.

Preparar entornos reproducibles para desarrollo y despliegue.

🛠️ Tecnologías utilizadas

Docker: Plataforma para crear, distribuir y ejecutar contenedores.

Docker Desktop: Entorno de trabajo Docker para Windows y macOS.

Docker CLI: Interfaz de línea de comandos para gestionar contenedores e imágenes.

Docker Hub: Registro de imágenes Docker.
